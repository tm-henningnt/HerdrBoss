# I want to answer a question

An agent asks you a question when it cannot decide. Use these tasks to answer, to talk with the Boss, and to send a picture. Words in *italics* are in the [glossary](../glossary.md).

## Answer in the Mailbox

1. Select the **Needs action** icon in the top bar. It has the warning color and opens the Mailbox.
2. Open the folder **Needs you**.
3. Select the first row to open its conversation.
4. Answer the item. For an approval, select **Approve** or **Reject**. For a decision, select a choice. For a question, type the answer and select **Send**.
5. Confirm the send when the page asks.

You should see the item leave **Needs you**. The conversation shows your answer with its delivery state. The agent receives the answer and continues.

If the folder says "Nothing needs you.", no agent waits for you. If the delivery state is **Failed**, the answer did not reach the agent. Tell the Boss in the *Chat*.

## Close an item that you answered elsewhere

1. Open the item in **Needs you**.
2. Select **Close as answered elsewhere**.

You should see the item move to **Done**. The page sends no message.

If you do not want to answer, select **Dismiss** on the item. The agent then gets no answer.

## Talk in the Chat

Use the Chat for a normal conversation. Use the Mailbox for a question that needs an answer.

1. Select the Chat icon in the top bar.
2. Select the Boss or a project lead in the list.
3. Type your message in the field at the bottom.
4. Select the round send button, or press Enter.

When you open Chat, the page refreshes the chat list.

You should see your message at once. The reply of the agent follows. A message that asks for a decision shows buttons. Select a button to answer.

If your message shows **Retry**, the service did not take it. Select **Retry**. If it fails again, run `herdr-boss doctor` and see [trouble.md](trouble.md).

## Send a picture

1. Open a conversation in the Mailbox or the Chat.
2. Select **Attach a picture**.
3. Choose a picture from your photo library or take one with the camera.
4. Add text if you want. Send the message.

You should see a small picture in the conversation. Select it to open the full picture. You can attach up to 6 pictures, each at most 10 MB. The types are JPEG, PNG, WebP, GIF, HEIC, and HEIF.

If the page refuses a picture, it is too large or has another type. Choose a smaller picture or export it as JPEG.

## Get messages on the home screen

Add the dashboard to the home screen of your phone. The steps are in [phone.md](phone.md).

You should see a count on the **Needs action** icon when an item needs you. The icon is faded when nothing waits.

If the count does not change, reload the page. The page also reads new data every 30 seconds.

For the folders, the item types, and the limits, see the [Mailbox reference](../reference/dashboard.md#mailbox) and the [Chat reference](../reference/dashboard.md#chat-page).
