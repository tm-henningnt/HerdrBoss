# I want to review a pack

A *review pack* is a set of *items* with evidence. A project lead or a planning session sends it when it needs your judgment on finished work. You judge each item. Words in *italics* are in the [glossary](../glossary.md).

## Open a pack

1. Select **Reviews** in the menu, or open the pack from its Mailbox item.
2. Find the pack in the folder **Open**.
3. Select the pack.

You should see the sections of the pack. Each row shows a type icon, a title, and a state. A bar at the top shows how many items are accepted, denied, or still open. The label `N of M items answered` shows your progress. A small note under the summary shows the judge pass that ran on the pack, or `no judge pass`.

If the list is empty, no pack waits. Ask the project lead in the *Chat* if you expect one.

## Judge an item

1. Select an item row to open the item.
2. Look at the evidence. Pinch to zoom a picture. Swipe left for the next item and right for the previous item.
3. Select **Accept** or **Deny**. Select the same button again to clear your choice.
4. Select **Note** to add a comment. The page saves it after you stop typing.
5. For a choice, select one of the option cards. The card marked **Recommended** is the suggestion of the agent.

You should see your decision on the item row. The page saves each answer at once. The badge on an item says `agent-verified`, `needs-you`, or `unmarked`. Start with the `needs-you` items. Select **Needs you** above the sections to show only those items.

If the item shows **Changed**, the agent changed it after your answer. It counts as open. Judge it again, or select **Keep** to restore your first answer.

## Ask for a live check

A live check opens the real result so that you can try it yourself.

1. Open the item.
2. Select **Live**.
3. Select a link in the live row. It opens in a new tab.
4. Try the result. Come back and select **Checked**.

You should see the state **Needs live check** until you select **Checked**. Select **Live** again to clear the mark.

If the link does not open, the preview or the service is not running. Add a note and tell the project lead.

## Submit

1. Scroll to the summary below the sections.
2. Read the list of denied, live, and open items.
3. Write a note for the whole pack in the note field. The note belongs to this version. A new version starts with an empty note. The note of an older version shows read-only with its version number.
4. Check the computed verdict. The page selects **Accept pack** when you accepted every item and wrote no note text. The page selects **Accept with changes** when any item or the pack note has text, or when any item is denied, open, or needs a live check. Choose another verdict if you want. **Deny pack** is never computed.
5. Select **Submit review**.
6. Confirm the verdict in the dialog. The dialog shows the verdict that the page sends. If you choose **Accept with changes** and no note has text, the dialog, the stored result, and the message to the project lead show `No change text`.

You should see the summary become read-only with your verdict. The result shows **Delivered** when the agent has received it. If items are open, the page asks `N items are still open`. Select **Answer them first** or **Submit anyway**.

If the result shows **Failed**, select **Queue again**.

## What happens next

The project lead reads your result. It fixes the denied items and starts the next task. When it fixes an item, it sends a new version of the pack. The pack then shows **N changed** in the list. Open the pack again and judge only the changed items. A new version starts with an empty pack note. The note of the older version stays on that version.

The pack moves to the folder **Done** after you submit it. Herdr Boss deletes a closed pack after 30 days.

For the item types, the keys, and the limits, see the [Reviews page reference](../reference/dashboard.md#reviews-page).
